HOW TO PUBLISH
1. Open https://github.com/dhanushpranave40235-cmd/MOTION-INVITATION
2. Delete the old "video-frames" folder files if you like (not required).
3. Click Add file > Upload files. Drag in everything from the unzipped folder
   (index.html, style.css, script.js, poster.jpg, .nojekyll, frames, video).
   Same names = GitHub asks to replace; choose Commit changes.
4. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
5. Wait 1-2 minutes, then open the link shown on that Pages screen.
   On a phone, reload twice or open in a private tab to skip old cached files.
